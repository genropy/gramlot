Minimal dbSelect
~~~~~~~~~~~~~~~~

.. code-block:: python

   from gramlot.contrib.fastapi_genropy import GenropyPage
   from gramlot.page import endpoint


   class Page(GenropyPage):
       def main(self, root):
           root.dbSelect(value='^customer_id', rpcmethod=self.customers, lbl='Customer')

       @endpoint
       def customers(self, _querystring='', _id=None):
           where = '$id=:key' if _id is not None else '$account_name ILIKE :text'
           rows = self.db.table('invc.customer').query(
               columns='$id,$account_name', where=where, key=_id,
               text=f'%{_querystring}%', order_by='$account_name,$id', limit=10).fetch()
           return dict(self.selection_result(rows, identifier='id'), caption='account_name')

   from gramlot.page import WebPage, endpoint


   class Page(WebPage):
       def main(self, root):
           root.remoteSelect(value='^choice', rpcmethod=self.choices, lbl='Choice')

       @endpoint
       def choices(self, _querystring='', _id=None):
           rows = [dict(id='a', name='Alpha'), dict(id='b', name='Beta')]
           rows = [r for r in rows if (r['id'] == _id if _id is not None
                                      else _querystring.lower() in r['name'].lower())]
           return dict(rows=rows, identifier='id', caption='name')

Behavior and limits
~~~~~~~~~~~~~~~~~~~

* Documents, active tab, saved baseline and revision live in Data Bags. Closing a dirty document requires explicit discard. Save errors retain edits.
