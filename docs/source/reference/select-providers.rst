dbSelect
--------

Select a record identity through an explicit database lookup endpoint.

Collection: ``inputs``. Tag: ``gnr-dbselect``.

Server required: yes.

Child tags: none.

Parameters
~~~~~~~~~~

* ``rpcmethod`` — @endpoint method | logical method name; required; default: ``null``.

  Explicitly exposed data endpoint. Python accepts the decorated bound method or its logical name.

* ``value`` — identity | Data binding; optional; default: ``null``.

  Selected identity, not caption. Use ^path for two-way Data binding. Identity is normalized to a string in the browser; null clears the selection.

* ``kw_*`` — any | Data binding; optional; default: ``null``.

  Provider parameters: the prefix is removed and bindings are resolved on each request. Use =path for dependent scope. Clear dependent selections explicitly when that scope changes.

* ``searchdelay`` — number; optional; default: ``300``.

  Debounce delay in milliseconds before text search.

* ``selectedCaption`` — Data path; optional; default: ``null``.

  Destination receiving the caption when the user chooses a row.

* ``selected_*`` — Data path; optional; default: ``null``.

  Destination receiving the selected record field named after the prefix. A missing field writes null. These outputs are not automatically cleared when value is cleared.

* ``lbl`` — string; optional; default: ``null``.

  Field label through the shared control decoration.

* ``placeholder`` — string; optional; default: ``null``.

  Hint shown by the empty input.

* ``disabled`` — boolean; optional; default: ``false``.

  Disable user interaction.

* ``readOnly`` — boolean; optional; default: ``false``.

  Prevent user editing.

* ``width`` — CSS length; optional; default: ``null``.

  Width through standard Gramlot styling.

Provider request
~~~~~~~~~~~~~~~~

* ``_querystring`` — string; optional; default: ``""``.

  Search text supplied by the widget. The provider owns matching and result limits.

* ``_id`` — identity; optional; default: ``null``.

  Exact identity lookup instead of text search, used to restore the caption of a stored value.

Provider response
~~~~~~~~~~~~~~~~~

* ``rows`` — array of records; required; default: ``null``.

  Rows with unique nonempty identities and non-null captions.

* ``identifier`` — string; required; default: ``null``.

  Name of the identity field in every row.

* ``caption`` — string; required; default: ``null``.

  Name of the display-caption field in every row.

* ``metadata`` — object; optional; default: ``{}``.

  Optional metadata retained on the component as resultMetadata.

Behavior and limits
~~~~~~~~~~~~~~~~~~~

* Uses filteringSelect keyboard and constrained identity selection behavior. Standard Gramlot bindings, field state and layout attributes remain available; this parameter list documents the provider contract and common controls.

* At most one provider request is in flight per SourceNode. Another request is refused with busy feedback, without queue or replay. Obsolete results are discarded. Clearing value invalidates cached choices and pending results.

* Providers must implement both text search and exact identity lookup. No SQL/table inference, automatic paging, legacy headers/data response, or multi-column popup is provided.

* These metadata describe the current runtime; they do not introduce strict parameter type validation.

* The example requires the optional FastAPI–GenroPy host and test_invoice_pg model. The component itself is database-agnostic; the endpoint owns database access and authorization.

Minimal dbSelect
~~~~~~~~~~~~~~~~

.. code-block:: python

   from gramlot.contrib.fastapi_genropy import GenropyPage
   from gramlot.page import endpoint


   class Page(GenropyPage):
       def main(self, root):
           root.dbSelect(value='^customer_id', rpcmethod=self.customers, lbl='Customer')

       @endpoint
       def customers(self, _querystring='', _id=None):
           where = '$id=:key' if _id is not None else '$account_name ILIKE :text'
           rows = self.db.table('invc.customer').query(
               columns='$id,$account_name', where=where, key=_id,
               text=f'%{_querystring}%', order_by='$account_name,$id', limit=10).fetch()
           return dict(self.selection_result(rows, identifier='id'), caption='account_name')

Minimal remoteSelect
~~~~~~~~~~~~~~~~~~~~

.. code-block:: python

   from gramlot.page import WebPage, endpoint


   class Page(WebPage):
       def main(self, root):
           root.remoteSelect(value='^choice', rpcmethod=self.choices, lbl='Choice')

       @endpoint
       def choices(self, _querystring='', _id=None):
           rows = [dict(id='a', name='Alpha'), dict(id='b', name='Beta')]
           rows = [r for r in rows if (r['id'] == _id if _id is not None
                                      else _querystring.lower() in r['name'].lower())]
           return dict(rows=rows, identifier='id', caption='name')

   class Page(WebPage):

           root.callbackSelect(value='^choice', lbl='Choice', callback="""
               const rows = [{id: 'a', name: 'Alpha'}, {id: 'b', name: 'Beta'}];
               return {rows: rows.filter(r => kw._id != null ? r.id === kw._id
